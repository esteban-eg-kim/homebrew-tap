# esteban-eg-kim/homebrew-tap

Homebrew formulae and casks for [hivemux](https://github.com/esteban-eg-kim/hivemux)
[dockpin](https://github.com/esteban-eg-kim/dockpin) and [winlego](https://github.com/esteban-eg-kim/winlego).

```sh
brew install esteban-eg-kim/tap/hivemux
hivemux setup
```

```sh
brew install --cask esteban-eg-kim/tap/dockpin
```

```sh
brew install --cask esteban-eg-kim/tap/winlego
```
